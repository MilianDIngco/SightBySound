Steps for Stereo Vision
1. Image Acquisition (fixed distance cameras capture images)
2. Rectification (If they are lying on different planes, need to rectify) (i don't need to do this)
3. Feature Detection (Identifying features in the images like edges, corners or patterns
4. Stereo Matching (Finding the disparity of features in the two images)
5. Depth Map Generation (Assigning depth values to each pixel in the image)
6. 3D Reconstruction (Reconstructing a 3D model of the scene; unneccessary, only need depth map)

Current Step
3. Feature Detection

Potential Tactics:
1. Block Matching: comparing small blocks of pixels in the two images to find the best match
2. Semi-Global Matching: Uses a dynamic programming approach to find optimal disparity map (more accurate than block matching but more expensive)
3. Census Transform: Uses local feature descriptor to match corresponding points; fast and efficient
4. Rank Transform: Uses rank of pixel intensities within a window to find correspondences; robust to noise and illumination changes

Attempts to implement a "sparse rank based stereo matching algorithm"

Proposed implementation tactics to improve performance
- combining a sparse rank transform with a composition of 1-D and 2-D box-filtering algorithms to reduce computational complexity
- using a Neon single instruction multiple data (SIMD) operation scheme to speed up rank computations and SAD correlation stages
- use of circular buffers reduces memory utilization during rank computation
- raw disparity map's quality improved by combining left-right consistency check, occlusion filling, and morphological closing operations
